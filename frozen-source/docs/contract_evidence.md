# Contract-evidence ledger for O1--O8

Status: public protocol evidence ledger, version 1.1, 2026-08-31. This ledger
separates source or destination contracts from cross-API preservation mappings
and study policies. It is not evidence that any prospective finding exists or
is a defect. Every publication-grade root must still cite the exact tagged
source lines, demonstrate applicability on its witness, and pass replay,
causal, reversion, and regression gates.

## Evidence classes

- **Direct contract:** documented or executable behavior explicitly specified
  by a pinned source/destination project.
- **Derived preservation mapping:** a cross-API relation needed to preserve the
  source task; it is not a destination-local API requirement by itself.
- **Study policy:** a prespecified interpretation or support boundary used for
  reproducible testing. A violation remains a `mismatch` unless an unambiguous
  external contract or maintainer disposition upgrades it.

## Cross-cutting adjudication rules

1. Destination-local API conformance and source-task preservation are separate
   questions. Passing `api_test` neither proves nor is intended to prove O1--O8.
2. Contract evidence is pinned to released versions. Current-main behavior or a
   later patch is reported separately and cannot rewrite the historical subject.
3. `evaluated_pass` means no linked finding across the applicable sites observed
   on one recorded prefix. It is not semantic equivalence or a claim about
   unvisited actions, configurations, schedules, or chance distributions.
4. A recorded internal clock/state/configuration discrepancy is not described
   as consumer-visible unless the evidence shows a changed public observation,
   reward, legal-action exposure, termination/truncation, agent lifecycle, or
   another public output.
5. Contract ambiguity yields `mismatch`; a known unsupported special kind yields
   `unsupported_capability`; oracle errors and harness faults remain separate.
6. Project-defined comparators are ablations over the same paired trace. Their
   results establish diagnostic complementarity only with same-root causal
   attribution and witness reachability, not independent replication.

Contract-bearing source references use released version tags and exact line
ranges. Pull-request links are retained only as historical context and are not
treated as independent proof of the current subject's contract.
